A. Karunamurthy1, K. Vijayan2, Pravin R. Kshirsagar3 & Kuan Tak Tan4
Federated Learning (FL) allows the learning models in distributed systems to be trained by sharing the 
network data and model parameters. The attack patterns of attackers are frequently upgraded as well 
as the technology improves. Machine learning-based intrusion detection is familiar for cybersecurity 
in IoT networks. However, these traditional procedures mainly focus on training the machine learning 
model through specific data and parameters. This might reduce the detection performance of IDS as 
the system doesn’t have insightful knowledge about the new attack patterns. Analyzing and detecting 
intrusions by analyzing diverse attack patterns is complex for machine learning algorithms. To 
overcome this, a federated learning-based intrusion detection approach is presented in this research 
work that trains deep learning classifiers in IoT networks through federated learning and detects 
different attacks. The Chimp optimization algorithm is used in the proposed work to select optimal 
features. Experimentations using the benchmark MQTT dataset validate that the FL-based IDS 
proposed in this research provides a maximum detection accuracy of 95.59% in detecting intrusions 
over traditional machine learning algorithms.
Keywords Federated learning, Deep learning, Intrusion detection, Network data, Security, Internet of things 
(IoT)
Over a decade, machine learning algorithms have been considered as an effective mechanism to detect intrusions 
in a network. Numerous ML-based IDS are developed to detect intrusions in IoT networks and other wireless 
sensor networks. However, the major limitation of ML-based IDS is its large and diverse dataset requirement for 
training the network. Practically providing a large dataset for ML models to train the network is challenging, and 
this challenge has increased in recent times due to dynamic, distributed heterogeneous networks. Besides this, 
ML models face privacy and security issues due to their centralized characteristics. The chances of data leakage, 
data breach, and unauthorized access decrease the confidence in adopting ML in data-sensitive applications1. To 
overcome these challenges, Federated Learning (FL) has been presented recently to enable distributed learning 
features without compromising security and privacy factors. The inherent heterogeneity and vast volume of IoT-
generated data exacerbate these limitations, making it increasingly difficult for centralized ML models to adapt 
to evolving attack patterns and maintain data privacy. These challenges underscore the need for decentralized, 
privacy-preserving, and scalable solutions. To address these issues, the proposed framework introduces a 
Federated Learning (FL)-based IDS that leverages the collaborative power of FL to train models across distributed 
devices without compromising sensitive data. By integrating a novel Chimp Optimization Algorithm for feature 
selection, the framework ensures reduced dimensionality of network data and improved classification accuracy. 
This dual combination of FL and optimized feature selection introduces a unique approach to enhancing both 
detection performance and data privacy in IoT environments. The novelty of the proposed framework lies in its 
ability to efficiently handle complex attack scenarios, including Distributed Denial-of-Service (DDoS) and brute 
force attacks, by combining decentralized learning, advanced optimization, and deep learning classifiers. These 
contributions position the proposed model as a significant advancement in intrusion detection for IoT networks.
Using FL, multiple clients can train a common model without disclosing private information 2. The model 
can be trained by each client locally using their own data without sharing it with the central server. The client’s 
model parameters are shared with central servers. The FL aggregator aggregates the client model updates and 
provides a global model to the client for further processing. The clients replace the current model with a global

Recently various FL-based IDS have been developed by the research community, and most of the models 
perform better than traditional machine learning-based IDS 4. Traditional Intrusion Detection Systems (IDS) 
face significant challenges in IoT environments due to the decentralized nature of these networks and the volume 
of data generated by interconnected devices. Centralized machine learning models are commonly used to detect 
cyberattacks but it requires large datasets and involve privacy risks as sensitive information must be transmitted 
to a central server for analysis. Deep learning models are widely preferred over ML models in various domains5,6. 
Similarly, some of the deep learning models perform better in detecting different types of intrusions7. However, 
to provide a decentralized approach to detecting intrusions and experiencing different types of attack patterns, 
the FL-based IDS are popular among network environments. The features from the network data are selected 
directly by the deep learning models, which might increase the complexity of the classification process. To 
address these challenges, this research proposes a Federated Learning-based Intrusion Detection System (FL-
IDS) that utilizes the features of Federated Learning (FL) and the Chimp Optimization Algorithm. FL allows 
multiple IoT devices to collaboratively train a model without sharing raw data which enhances the privacy. 
The Chimp Optimization Algorithm is applied to perform feature selection. The essential features from the 
network traffic data are selected by the optimization algorithm thus, it will reduce the complexity and increase 
the detection accuracy of the classifier. Moreover, due to the updated global parameters, all the clients will 
experience this improved detection accuracy. The objective of proposed technique is to handle the complex 
cyberattacks. Since IoT networks are frequently targeted by multiple attacks such as distributed denial-of-service 
(DDoS), brute force, and data poisoning attacks. These attacks introduce vulnerabilities in distributed systems 
and traditional IDS approaches struggle to handle this evolving threat patterns. By distributing the learning 
process across devices and selecting the most critical features the proposed optimized FL-IDS for IoT network 
provides enhanced detection accuracy and ensures privacy. The research work made the following contributions.
• A decentralized Federated Learning-based Intrusion Detection System (FL-IDS) is presented for IoT net -
works. The proposed method improves data privacy and security by allowing local devices to train models on 
their own data and share only the model parameters with a central server for aggregation which secures the 
sensitive information.
• Proposed a novel optimal feature selection model using Chimp Optimization in the IDS domain to ensure 
efficient feature selection. This reduces the dimensionality of network traffic data and enhances classification 
accuracy.
• The remote IoT instances are provided with convolutional neural network-based IDS with different param -
eter settings. Further, through FL-aggregation, the parameters are aggregated to create a global model and 
shared with clients to attain improved detection accuracy in all instances.
• Detailed experimental evaluation of the proposed model is presented a using a benchmark MQTT dataset, 
which has different IoT device traffic data. The Proposed model performance is evaluated and compared with 
conventional ML models like decision tree, random forest, neural network, gradient boost and naïve bayes al-
gorithms. With a detection accuracy of 95.59% the proposed model performs better than traditional machine 
learning-based IDS approaches. This highlights the proposed model ability in effectively detect multiple types 
of intrusions in IoT environments, including advanced attacks like DDoS and brute force attacks.

Related works
Recent research works on Intrusion detection in IoT environments are presented in this section. Selecting 
suitable ML model for malicious traffic classification is an important process. The review work presented in 8 
analyzes various ML model performances which are suitable for smart city traffic classification. selecting suitable 
ML to handle the cyber-attacks in smart city is addressed in 9. The presented model selects the optimal features 
from network data and then utilizes ML algorithms to classify the attacks. Machine learning-based IDS faces 
difficulty in detecting intrusions due to the enormous amount of data and distributed network-connected 
devices. By addressing this, an FL-based IDS was proposed in 10, which shares local parameters with a central 
server and aggregates to generate a global model. Based on the global model parameters, the clients are modified 
and trained with local data to detect intrusions in the IoT network. Experimentation using the Edge IIoT dataset 
attained an accuracy of 92.49%, which is slightly higher than ML-based approaches.
The FL-based IDS presented in11 includes a discriminator network for attack detection in IoT edge devices. 
Using deep learning model, feature extraction is performed and through discriminator network the features 
are classified. Reduced incorrect prediction and improved security are the features of the presented FL-IDS 
model. The FL based IDS presented for Industrial IoT environment addresses the heterogeneity issues in the 
FL aggregation12. The detect attacks in the client instances an unsupervised device clustering procedure was 
presented in this research which detects the presence of various attackers in IIoT network. For DDoS attack 
detection, a federated integrated network IDS was presented in13 which analyzes the anomalous behavior through 
HIDS and detect attacks in the network. Additionally using federated learning, the local system parameters are 
updated to detect the anomalous traffic. Using this federated learning procedure, the detection accuracy was 
improved and privacy issue in decentralized infrastructure is reduced.
The IDS presented in14 utilizes FL to share the weights of local models and update with global model parameters 
in IoT environment. The presented Federated averaging procedure utilizes different learning algorithms in client

models are utilized. Including optimization model for better feature processing will enhance the intrusion 
detection performance. Thus, in this research work an optimal FL-based IDS was presented to for intrusion 
detection in an IoT environment.
Proposed work
The proposed optimal FL based IDS for IoT Environment aimed to detect different intrusions in IoT environment. 
The complete overview of the proposed FL-based ID model is presented in Fig.  1. The high-level architecture 
includes multiple IoT instances distributed at different sites. All the IoT instances are connected through 
gateways, and the network data will be shared through the gateway. An intrusion detector will be placed in the 
security gateway for monitoring the IoT instance traffic data. This makes the architecture more independent 
and intelligent so that the system does not need to rely on traditional server-device mechanisms and procedures 
for decision-making. Also, this intelligent detection mechanism reduces the detection time by analyzing the 
shared network data. Federated setup is introduced in the gateway arrangement. For every stipulated time, the 
learning models used in the IoT instances will be trained on local network data. Then, the model parameters are 
aggregated to create a global model so that more sophisticated detection performances can be obtained for all the 
models. The main feature of FL in the research work is to share the learning models with server and aggregating 
the learning models will provide a global intelligence model which can able to detect the attacks with higher 
accuracy than traditional modes. The global optimized model used in the gateways increases the knowledge of 
gateways about empowers IoT instances to detect intrusions better manner.
The proposed architecture for the Federated Learning-based Intrusion Detection System (FL-IDS), as shown 
in Fig. 1, is designed to effectively address key challenges in IoT environments, such as scalability, data privacy,

and computational efficiency. At its core, the architecture is built around distributed IoT instances, which act 
as data generators and execute local intrusion detection using trained Convolutional Neural Network (CNN) 
models. These instances enable decentralized processing, ensuring data privacy by keeping raw data within 
local devices and significantly reducing the risk of data breaches. Security gateways serve as intermediaries 
between the IoT instances and the central server. These gateways play a crucial role in managing the data flow, 
hosting the feature selection module, and executing localized intrusion detection tasks. By processing data at 
the gateway level, the architecture reduces the reliance on centralized systems, lowering latency and enhancing 
fault tolerance. The feature selection module, powered by the Chimp Optimization Algorithm, optimizes the 
dataset by identifying and selecting the most relevant features from network traffic data. This step is essential for 
reducing the dimensionality of the data, improving classification accuracy, and minimizing the computational 
load, especially in resource-constrained IoT devices.
Each IoT instance is equipped with a local CNN-based learning model that processes the optimized feature 
set for training. These local models are periodically updated and shared with a Federated Aggregation Server. 
The server aggregates the parameters from all local models to create a global model, which is redistributed back 
to the IoT instances. This global model ensures consistency across the system and enhances the detection of 
evolving attack patterns, such as Distributed Denial-of-Service (DDoS) and brute force attacks. The integration 
of Federated Learning with optimization ensures privacy-preserving data processing while maintaining high 
detection accuracy. This innovative combination makes the architecture scalable, efficient, and adaptable to 
heterogeneous IoT environments, distinguishing it from traditional IDS solutions.

Next to optimal feature selection, the architecture has learning models. In the proposed work convolutional 
neural network is used for training procedures. The CNN model has multiple convolution and pooling layers 
and provides classification outputs which will be used to analyze the intrusions. The CNN model will be trained 
with different patterns of attacks and the final SoftMax function classify the network traffic into different attack 
categories. The optimal features selected by the optimization models are given as input to the deep learning 
classifier. The temporal information in the feature sets is learned by the CNN and get trained to detect the attacks. 
Once the model is trained, the trained CNN model will be shared among other IoT instances for detecting 
attacks in the real time network data of IoT devices.
The federated learning procedure is associated will all the IoT instances. Each instance connected in the 
architecture will have a training data and using the shared view of learning model the classifier in the instance 
gets trained. Once it gets trained, the parameters are shared with the central server for aggregation. The process 
of federated learning is simplified in the following steps.

Results and discussion
For the proposed model evaluation, the experimentation utilizes MQTT protocol dataset which is available in 
Kaggle repository30. This dataset simulates real-world IoT device communications and contains both normal 
and attack traffic. The attack types include.
• Brute Force Attack - A type of cyberattack where multiple login attempts are made to gain unauthorized 
access.
• Flooding DoS (Denial of Service) - An attack that overwhelms the network with excessive data, leading to 
disruption.
• MQTT Publish Flood - A targeted attack on the MQTT protocol, causing a flood of publish requests to over-
whelm the system.
• Malformed Data Attack - An attack that involves sending corrupted or unexpected data to exploit system 
vulnerabilities.
• SlowITe Attack - An advanced attack that uses slow HTTP connections to exhaust server resources.

In the experimentation process, the data in the MQTT dataset is processed initially by the Chimp 
Optimization Algorithm to reduce the dimensionality of the dataset by selecting the most relevant features 
from network traffic data. This step ensures that the classifier receives only the most critical information and 
reduces the computational complexity and increases the accuracy. After optimal feature selection, in the local 
model training, each IoT instance in the federated learning setup trained its own CNN model using local data. 
Further in the Federated Aggregation, the trained models from each instance were sent to the central server and 
the parameters are aggregated to form a global model. Finally, to test and evaluate the model, the global model 
is then tested and performance metrics such as accuracy, precision, recall, and F1-score are computed. The 
proposed model performance is comparatively evaluated with existing machine learning models like Multilayer

Conclusion
In this research work, an optimal federated learning-based IDS for IoT environment is presented. The concept 
of sharing the network parameters and developing a global model to ensure maximum accuracy in intrusion 
detection is incurred through the federated learning procedure. The presented IDS has optimal feature selection 
module which selects the optimal features from the network data to detect the intrusions. The deep learning 
classifier detects different types of intrusions based on the learning parameters provided by the FL global model. 
The detection performance is improved using the federated learning procedure compared to traditional machine 
learning based intrusion detection models. Experimental analysis which utilizes MQTT dataset validates the 
performances of proposed FL-CNN and conventional machine learning models. The maximum detection 
accuracy was attained by the proposed FL-CNN in detecting different types of attacks. Though the proposed 
model better detection performance it has few limitations. If the local model gets affected and sends wrong 
parameters for model aggregation due to malicious data in the local training, then it will affect the global model 
accuracy. Also, the optimization algorithm slightly increases the computational complexity in IoT systems. To 
overcome this in future, computationally efficient federated learning techniques can be developed which suitable 
resource-constrained IoT devices such as low-power edge devices or sensors.
